# Менеджер фотографий

**Десктопное приложение для организации, хранения и редактирования фотографий**

Занял **1 место** на конкурсе ШКОЛА РЕАЛЬНЫХ ДЕЛ.

## Основные возможности

- Удобная система папок и управление фотографиями
- Адаптивная сетка миниатюр с автоматическим пересчётом колонок
- Полноценный редактор изображений:
  - Обрезка (crop) с визуальным выделением
  - Рисование кистью с выбором цвета и размера
  - Стирание с поддержкой прозрачности и сглаживанием
  - Поворот на 90°, отражение по горизонтали
  - Изменение размера изображения
  - Применение фильтров (размытие, резкость, контур, тиснение и др.)
- История действий с возможностью отмены (undo)
- Навигация между фотографиями с помощью стрелок и миниатюр
- Сохранение структуры папок и данных в JSON-файл

## Технологии

- **Python 3**
- **Tkinter** + Canvas
- **PIL (Pillow)** — обработка изображений
- JSON для хранения данных

## Как запустить
1. Скачай репозиторий
2. Установи зависимости: `pip install pillow`
3. Запусти: `python PhotoManager.py`
